# ColorsHD — Modernization Roadmap

ColorsHD is preserved as an early educational-app distribution archive. The current repository contains Android and Unity/Windows build artifacts, not the editable Unity source project.

## 10 tasks

1. Recover the original Unity `Assets/`, `Packages/` and `ProjectSettings/` directories if backups still exist.
2. Record provenance, version, signing/package information and checksums for the historical APK/AAB/EXE builds before redistribution.
3. Move future generated binaries to GitHub Releases or artifact storage rather than treating compiled outputs as canonical source.
4. Replace unsupported educational claims with evidence-based product language focused on color recognition and English pronunciation exposure.
5. Redesign the experience for short caregiver-guided sessions instead of implying unsupervised passive screen use.
6. Audit all SDKs, permissions, analytics, crash reporting and network behavior before any Android re-release.
7. Write a current child-privacy policy only after the actual modern build and target markets are defined; do not reuse the contradictory 2021 text.
8. Add accessibility controls for audio, motion/transition timing, readable labels and non-audio alternatives where appropriate.
9. Create a portfolio case showing the product evolution from the early packaged ColorsHD app to later browser/TTS learning experiments, without implying source code that is not preserved here.
10. If source recovery fails, retain this repository as a clearly labeled historical build/design archive rather than presenting it as an actively maintainable Unity codebase.

## Modern product direction

A credible modern version would prioritize a small, privacy-conscious learning loop: color presentation, clear spoken label, caregiver control, predictable timing, no behavioral advertising and no unnecessary data collection.

## Portfolio decision

Useful as evidence of early product experimentation and shipped/package-level mobile work, provided the distinction between design/product work, compiled artifacts and missing editable Unity source remains explicit.
